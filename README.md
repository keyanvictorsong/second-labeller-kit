# Labelling kit: 150 code locations

A labelling task for a research study on a security scanner: 150 code locations, about four hours, for someone who
reads TypeScript or JavaScript.

## How to start

1. Download `SecondLabeller_v2_0_handover.zip` from this page (click the file name, then the download button).
2. Extract it and keep the folder in one place.
3. Read `READ_ME_FIRST.md` in that folder and follow it. The work is done in `LABELLING_DESK.html`, opened in Chrome
   from your disk.
4. When you are done, send the one answers file to the person who gave you this link.

Please look at nothing else about the study before you have sent your answers file.

## What is here

- `SecondLabeller_v2_0_handover.zip`: the kit, a read-me and one page. SHA-256 `0097561f467e84f4f97bb9e849e6ca64ce24f4a0bbeb43563d7e6cbd68ccb0ec`.
